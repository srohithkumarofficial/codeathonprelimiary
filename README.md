# CachePulse

CachePulse is a cache-performance engineering platform for measuring in-memory cache behavior, comparing LRU and LFU under controlled workloads, and understanding how workload shape affects measured results. Its healthcare-oriented profiles are deterministic simulations using synthetic keys; they do not use patient data or represent any organization's production systems.

## Run locally

Requirements: JDK 17 or newer, Node.js 20 or newer, and internet access for the first dependency download. On Windows, set `JAVA_HOME` to the JDK installation directory if it is not already set.

In PowerShell:

```powershell
cd backend
.\mvnw.cmd test
.\mvnw.cmd package
.\mvnw.cmd spring-boot:run
```

In a second terminal:

```powershell
cd frontend
npm install
npm run dev
```

Open http://localhost:5173. Vite proxies `/api` requests to Spring Boot at localhost:8080. Set `VITE_API_BASE_URL` to use a different API origin.

## What it demonstrates

- Live cache metrics, policy and capacity configuration, GET/PUT/remove/clear, and per-entry TTL.
- A Policy Lab that executes the same generated healthcare-oriented trace against fresh LRU and LFU caches.
- Workload measurements for unique keys, repeated accesses, top synthetic keys, exact per-key frequency distribution, concentration among the top 10% of keys, and recent reuse within a 50-request window.
- Neutral policy insights derived from measured hit and miss rates, eviction counts, and workload locality indicators.
- Concurrent GET/PUT stress runs against the shared live cache.

Policy results and workload analysis are generated by the backend at run time; dashboard metric examples and comparison results are not hardcoded.

## Design and API

`CacheEngine<K,V>` owns storage, expiry checks, capacity, counters, and its selected eviction strategy. A single lock keeps compound cache and policy state consistent. The metrics API reads maintained statistics snapshots and does not scan cache storage.
